# The Arcade

Game design patterns applied to product UX — progressive disclosure, engagement loops, interaction feel, reward systems, and economy design.

## Skills

| Command | What it does |
|---------|-------------|
| `/referencing-games` | Find game design parallels for your UX problem — deep structural mapping, not surface analogies |
| `/designing-progression` | Design progressive disclosure that teaches complex features through use, not tutorials |
| `/prototyping-mechanics` | Rapidly prototype an interaction mechanic to test if it feels right |
| `/designing-systems` | Design systems with core loops, feedback cycles, and emergent behavior |
| `/playtesting-loops` | Structure a playtest session to answer specific questions about feel and learning |
| `/crafting-feel` | Analyze and tune how an interaction feels — weight, timing, responsiveness, satisfaction |

## Install

```bash
npx loa-cli install the-arcade
```

## When to use

- Designing onboarding that teaches by doing, not explaining
- Building reward systems, streaks, or progression mechanics
- Your UI "works" but doesn't feel satisfying to use
- Designing an economy (tokens, points, credits) that stays balanced
- Need game design references that map to your specific product problem
